# 一起说英语

六个亲子英语生活小课堂，适合家长陪同的 3 岁左右孩子。点图听示范，麦克风按钮可自愿跟读回听；录音默认关闭、最多 12 秒，仅本次内存，不上传、不评分，关闭或换词即删除。

正式 HTTPS 地址请看本仓库 Settings → Pages。Safari 分享 → 添加到主屏幕；先下载全部课程并等到核验完成，再尝试离线。浏览器可能清理缓存，不保证永久保存。
